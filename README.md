# Практическое задание по дисциплине «Введение в HTML»

## Описание проекта

Данный проект содержит 4 HTML-страницы, демонстрирующие базовые принципы создания веб-страниц: работу с основными элементами HTML, построение структуры документа, добавление мультимедийного контента, создание форм и применение семантической разметки.

## Структура проекта

```
html-practice/
├── index.html          # Задача 1 — Базовая HTML-страница
├── about.html          # Задача 2 — Персональная веб-страница
├── feedback.html       # Задача 3 — Форма обратной связи
├── semantic.html       # Задача 4 — Семантическая разметка
├── photo/
│   ├── my_photo.jpg    # Фото для персональной страницы
│   └── logo.svg        # Логотип сайта
└── README.md           # Описание проекта
```

## Описание страниц

### index.html — Базовая HTML-страница
- Базовая структура HTML5-документа
- Заголовок первого уровня
- Абзацы с описанием HTML и его отличий от языков программирования
- Форматирование текста: жирный (`<strong>`), курсив (`<em>`), перенос строки (`<br>`)

### about.html — Персональная веб-страница
- Иерархия заголовков (`<h1>`, `<h2>`)
- Маркированный список увлечений (`<ul>`)
- Нумерованный список любимых книг (`<ol>`)
- Таблица навыков (`<table>`)
- Изображение с относительным путём (`<img>`)
- Абсолютная гиперссылка на внешний ресурс (GitHub)
- Якорная ссылка для навигации внутри страницы (`<a href="#about">`)
- Встроенное видео из RuTube (`<iframe>`)

### feedback.html — Форма обратной связи
- Текстовое поле для имени (обязательное)
- Поле для email с валидацией формата
- Группа переключателей для выбора пола
- Выпадающий список стран проживания
- Чекбокс согласия с условиями (обязательный)
- Кнопка отправки формы
- Атрибуты валидации: `required`, `type="email"`, корректное использование `name`

### semantic.html — Семантическая разметка
- Тег `<header>` с логотипом и названием сайта
- Тег `<nav>` с навигационным меню
- Тег `<main>` с тематическими разделами `<section>`
- Тег `<footer>` с контактной информацией

## Как запустить проект

### Способ 1 — Двойной щелчок
1. Скачайте все файлы проекта
2. Сохраните структуру папок (файл `logo.svg` должен лежать в папке `photo/`)
3. Дважды щёлкните по любому `.html` файлу — он откроется в браузере по умолчанию

### Способ 2 — Через VS Code
1. Откройте папку проекта в Visual Studio Code
2. Установите расширение **Live Server** (Ritwick Dey)
3. Откройте нужный `.html` файл
4. Нажмите **Go Live** в правом нижнем углу

### Способ 3 — Через терминал
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

## Требования
- Современный веб-браузер (Chrome, Firefox, Edge, Safari)
- Подключение к интернету для воспроизведения видео с RuTube
